# TASKORA – Smart Workspace

A modern and responsive SaaS landing page built to help freelancers and teams organize their work efficiently.

## Features

- Responsive Navbar with mobile menu
- Attractive Hero Section
- Features Section
- How It Works Section
- Starter and Professional Pricing Plans
- Interactive Dashboard
- Add and Delete Projects
- Local Storage Support
- Contact Form with Validation
- Responsive Design for all devices

## Technologies Used

- React.js
- Tailwind CSS
- JavaScript
- Vite
- Lucide React Icons

## Installation and Setup

Follow these steps to run the project locally:

1. Clone the repository:

   `git clone https://github.com/Nitesh77734/TASKORA`

2. Navigate to the project folder:

   `cd taskora`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL in your browser.

## Production Build

To generate the production build, run:

`npm run build`
